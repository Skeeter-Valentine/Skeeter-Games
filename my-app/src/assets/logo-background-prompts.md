# Matching homepage logo backgrounds

Created with the built-in image generator using each existing PNG as its own reference.
The twelve revised originals are `*-blend.png`; homepage exports are `*-blend.webp`
(640 x 640, WebP quality 90). Existing original images and Skitches are preserved.

Prompt used for each logo:

Precise background-only edit. Preserve this logo's exact text, all numbers and
symbols, all tiles and their colors, cream rounded border, typography and layout.
Replace only the navy background, both outside and inside the cream border,
with uniform deep indigo #0f0c1b to blend into a website of that color. Outer
corners and edges must be flat #0f0c1b with no bright halo. Do not redesign,
crop, alter any lettering, or add elements. Return the complete square logo.

Applied to Parshle, Skeedle Marathon, Skeedograms, Skeedle+, Skeeter Piper,
Shikaku, Ske4dle, Skeedle500, Mineskeeter, 2048, Hashkeet, and Skeedoku.
